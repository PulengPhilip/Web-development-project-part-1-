## Project Overview
Bright Spark Electrical Services is a fictional small electrical company founded in 2018. It started as a solo operation and grew to a three-person team through word-of-mouth referrals.

## Website Goals
1. Generate online service enquiries.
2. Build trust through experience, qualifications and completed work.
3. Improve local online visibility.
4. Provide an enquiry option outside business hours.
5. Make contact details easy to find.

## Key Features
- Responsive navigation
- Homepage with Get a Quote CTA
- About Us page
- Services page
- Quote enquiry form
- Contact page and Google Maps placeholder
- Qualifications/completed-work section
- Emergency call-out messaging
